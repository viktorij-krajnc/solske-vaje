# Šolske vaje – Viktorij Krajnc

Zbirka projektov v C#.

- [Vaja002](Vaja002/): Windows Forms, izposoja opreme, validacija in dogodki.
- [Vaja003](Vaja003/): konzolni projekt z menijem in šestimi podnalogami.

## Zagon

Za Vaja002 potrebujete Windows in razvojno okolje za .NET 8 Windows Forms. Odprite `Vaja002/DogodkiOprema.csproj`.

Za Vaja003 potrebujete .NET SDK 8 ali novejši. Odprite `Vaja003/Vaja003.csproj` ali izvedite `dotnet run --project Vaja003/Vaja003.csproj`.

Pri pripravi projektov, dokumentacije in preverjanj je bila uporabljena pomoč AI. Obseg preverjanj in omejitve so opisani ob posamezni vaji. Vaja002 temelji na priloženem šolskem začetnem primeru.
