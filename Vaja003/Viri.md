# Viri in omejitve

- Navodila za vajo 3 (`003-vaje.md`): zahteve za vseh šest nalog.
- Microsoft Learn, **Arithmetic operators**: celoštevilsko deljenje, deljenje z realnim operandom in ostanek `%`. https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/operators/arithmetic-operators
- Microsoft Learn, **Method parameters and modifiers**: argumenti se privzeto podajajo po vrednosti; pri `int` metoda prejme kopijo vrednosti. https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/method-parameters
- Microsoft Learn, **Static Classes and Static Class Members**: klic metod prek imena razreda brez ustvarjanja primerka. https://learn.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/static-classes-and-static-class-members
- Microsoft Learn, **Random.Next**: spodnja meja je vključena, zgornja izključena; `Next(1, 101)` zato izbira od 1 do 100. https://learn.microsoft.com/en-us/dotnet/api/system.random.next?view=net-8.0
- Microsoft Learn, **Console.ReadLine**: pri koncu vhodnega toka vrne `null`. https://learn.microsoft.com/en-us/dotnet/api/system.console.readline?view=net-8.0

Dokumentacija preverjena 20. 10. 2026. Gre za uradno dokumentacijo, ki pojasnjuje jezik in API, ne za dokaz o uspešnem izvajanju tega projekta. Dejanski rezultati izvajanja so navedeni v datoteki `Preverjanje.md`. Oblikovanje decimalnih števil je odvisno od nastavitev okolja: ista vrednost se lahko izpiše kot `2.5` ali `2,5`.
